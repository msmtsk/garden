# 🌿 Mary's Garden — инструкция по управлению сайтом

## Как добавить новый товар

Открой файл `products.json` на GitHub, нажми карандаш ✏️ и добавь новый блок в список.

### Шаблон товара

Скопируй этот шаблон и вставь перед последним `]`:

```json
,
{
  "id": "придумай-уникальный-id",
  "name": "Название сорта",
  "category": "Фиалки",
  "type": "Детка",
  "price": 250,
  "inStock": true,
  "quantity": 3,
  "description": "Описание сорта. Можно несколько предложений.",
  "author": "Имя автора сорта или оставь пустым: \"\"",
  "attributes": {
    "rozetteSize": "Стандарт",
    "flowerType": "Полумахровый",
    "color": "Цвет цветка",
    "petalEdge": "Форма края лепестка",
    "foliage": "Описание листвы"
  }
}
```

### Поля

| Поле | Обязательно | Описание |
|------|------------|----------|
| `id` | ✅ | Уникальный идентификатор, только латиница и дефисы. Должен совпадать с именем папки с фото |
| `name` | ✅ | Название сорта |
| `category` | ✅ | Из списка в `config.json` |
| `type` | ✅ | Детка / Срез / Взрослое / Укоренённый лист |
| `price` | ✅ | Цена в рублях, только цифры |
| `inStock` | ✅ | `true` — есть в наличии, `false` — нет |
| `quantity` | ✅ | Количество штук |
| `description` | — | Описание сорта |
| `author` | — | Автор сорта |
| `attributes` | — | Характеристики — все необязательны, пустые не показываются |

## Как добавить фото

1. Создай папку в `public/images/` с тем же именем что и `id` товара
2. Загрузи туда фото — любые имена, например `1.jpg`, `2.jpg`, `3.jpg`
3. Первое фото по алфавиту будет главным на карточке в каталоге

**Пример:**
```
public/images/
└── ek-serdce-korolevstva/
    ├── 1.jpg   ← главное фото
    ├── 2.jpg
    └── 3.jpg
```

## Как убрать товар из продажи

Найди товар в `products.json` и измени:
```json
"inStock": false
```

Товар останется на сайте, но будет помечен «Нет в наличии».

---

## Как настроить способы доставки

Открой `config.json`. У каждого способа доставки есть поле `"enabled"`:
- `true` — показывается на сайте
- `false` — скрыт

---

## Как добавить ссылки на Авито, ВКонтакте

Открой `config.json`, найди раздел `"contacts"` и вставь свои ссылки.
Пустая строка `""` — ссылка не показывается на сайте.

# 🌿 Mary's Garden — инструкция по управлению сайтом

🔗 **Сайт:** [msmtsk.github.io/garden](https://msmtsk.github.io/garden/)

---

## Локальный запуск

Нужен установленный [Node.js](https://nodejs.org/) (версия 18+).

```bash
# Установить зависимости (один раз)
npm install

# Запустить сервер разработки
npm run dev
```

После этого сайт откроется на [http://localhost:4321](http://localhost:4321). Изменения в файлах применяются мгновенно без перезапуска.

## Как добавить новый товар

Открой файл `products.json` на GitHub, нажми карандаш ✏️ и добавь новый блок в список.

### Шаблон товара

Скопируй этот шаблон и вставь перед последним `]`:

```json
,
{
  "id": "придумай-уникальный-id",
  "name": "Название сорта",
  "type": "Детка",
  "price": 250,
  "inStock": true,
  "description": "Описание сорта. Можно несколько предложений.",
  "attributes": {
    "rozetteSize": "Стандарт"
  }
}
```

### Поля

| Поле | Обязательно | Описание |
|------|------------|----------|
| `id` | ✅ | Уникальный идентификатор, только латиница и дефисы. Должен совпадать с именем папки с фото |
| `name` | ✅ | Название сорта |
| `type` | ✅ | Детка / Срез / Взрослое / Укоренённый лист |
| `price` | ✅ | Цена в рублях, только цифры |
| `inStock` | ✅ | `true` — есть в наличии, `false` — нет |
| `description` | — | Описание сорта |
| `attributes.rozetteSize` | — | Размер розетки: Мини / Полумини / Стандарт и т.д. |

## Как добавить фото

1. Создай папку в `public/images/` с тем же именем что и `id` товара
2. Загрузи туда фото — любые имена, например `1.jpg`, `2.jpg`, `3.jpg`
3. Первое фото по алфавиту будет главным на карточке в каталоге

**Пример:**
```
public/images/
└── ek-serdce-korolevstva/
    ├── 1.jpg   ← главное фото
    ├── 2.jpg
    └── 3.jpg
```

## Как убрать товар из продажи

Найди товар в `products.json` и измени:
```json
"inStock": false
```

Товар останется на сайте, но будет помечен «Нет в наличии».

## Как настроить способы доставки

Открой `config.json`. У каждого способа доставки есть поле `"enabled"`:
- `true` — показывается на сайте
- `false` — скрыт

---

## Как добавить ссылки на Авито, ВКонтакте

Открой `config.json`, найди раздел `"contacts"` и вставь свои ссылки.
Пустая строка `""` — ссылка не показывается на сайте.

## Водяные знаки на фото

Подпись *Maria* наносится автоматически при каждом `git commit` — трогать ничего не нужно.

Если хочешь нанести вотермарки вручную (без коммита):

```bash
# На все фото сразу
npm run watermark

# На конкретный файл
node scripts/watermark.js public/images/ab_kupidon/1.jpg
```

Уже размеченные фото повторно не обрабатываются — защита от наслоения встроена.

### Настройка надписи

Все параметры вотермарки находятся в начале файла `scripts/watermark.js` в блоке `CONFIG`:

```js
const CONFIG = {
  text: 'Maria',          // текст подписи

  xFraction: 0.72,        // положение по горизонтали: 0 = левый край, 1 = правый
  yFraction: 0.62,        // положение по вертикали:   0 = верх, 1 = низ

  fontSize: 52,           // размер шрифта в пикселях
  fontFamily: 'serif',    // шрифт (serif / sans-serif / monospace)
  color: 'rgba(180, 100, 180, 0.80)',       // цвет текста и прозрачность (0.0–1.0)
  strokeColor: 'rgba(255, 255, 255, 0.45)', // цвет обводки (для контраста на тёмном фоне)
  strokeWidth: 2,         // толщина обводки в пикселях
  rotation: -20,          // угол наклона в градусах (отрицательный = наклон влево)
};
```

После изменения параметров нужно перенанести вотермарки вручную — автоматически они не обновятся, потому что уже размеченные фото пропускаются. Чтобы перебить старые метки и нанести заново, придётся восстановить оригинальные фото и запустить `npm run watermark`.

> **Важно:** храни оригинальные фото (без вотермарки) отдельно — например, в Яндекс.Диске или локальной папке вне репозитория. В git попадают уже размеченные версии, и если оригиналы не сохранены заранее, восстановить их будет невозможно.
